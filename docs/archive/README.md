# Archiwum dokumentacji

Ten indeks prowadzi do 16 dawnych audytów, planów i notatek zachowanych w historii Git. Ich treść jest dostępna pod odnośnikami do konkretnej wersji repozytorium; nie powielamy jej w bieżącym katalogu dokumentacji. Archiwalne dokumenty nie są aktualną instrukcją obsługi ani listą potwierdzonych problemów obecnej wersji. Nawet sformułowanie „aktywny backlog” w starym raporcie opisuje stan z chwili jego powstania. Niektóre opisy odnoszą się do dawnego schematu bazy lub interfejsu.
